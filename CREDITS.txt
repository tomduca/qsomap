INSPIRACION Y REFERENCIA
========================================

QSO Map
Autor: Ian Renton M0TRT
Website: https://ianrenton.com
Repositorio original: https://git.ianrenton.com/ian/qsomap.git
Licencia declarada por el proyecto original: MIT License

Este proyecto esta inspirado en la solucion QSO Map de Ian Renton. Tomamos como referencia:
- La idea de representar QSOs de radioaficionados sobre un mapa.
- El uso de grids Maidenhead para ubicar estaciones.
- La representacion de una estacion propia, contactos y trayectorias.
- La organizacion general de los datos de QSO y la generacion de un cache para el visor.

La implementacion actual del visor es una version simplificada y adaptada. No carga scripts desde Ian Renton ni desde sus dominios. Las conversiones Maidenhead, las lineas de gran circulo, los filtros SSB/DIGI/QSL y la interfaz actual fueron implementados para este proyecto.

========================================
MEJORAS Y ADAPTACIONES
========================================

Implementadas para LU2MET por Tomas Duca
Repositorio: https://github.com/tomduca/qsomap

- Visores simples para SSB, DIGI y QSL confirmados por LoTW mediante `QSL_RCVD = Y` de Clublog.
- Marcadores pequenos coloreados por banda.
- Agrupacion de marcadores superpuestos.
- Lineas de gran circulo calculadas localmente y usando la ruta longitudinal mas corta.
- Repeticion horizontal del mapa para visualizar trayectorias hacia Asia y el Pacifico.
- Popups con los datos disponibles del cache y nombre de entidad DXCC.
- Sincronizacion con Clublog y fallback a LoTW.
- Cache incremental y lookups server-side de grids mediante HamQTH y Spothole.
- Documentacion para instalacion con File Manager y Cron de cPanel.

========================================
BIBLIOTECAS Y SERVICIOS UTILIZADOS
========================================

BIBLIOTECAS FRONTEND:
- Leaflet.js 1.9.4 - https://leafletjs.com/
  Biblioteca de mapas interactivos. Licencia BSD-2-Clause.
- Leaflet Providers - https://github.com/leaflet-extras/leaflet-providers
  Catalogo de proveedores para capas base. Licencia MIT.
- OverlappingMarkerSpiderfier - https://github.com/jawj/OverlappingMarkerSpiderfier-Leaflet
  Agrupa visualmente marcadores superpuestos. Licencia MIT.

MAPAS:
- Esri World Maps, incluido Esri.NatGeoWorldMap.
  Se utiliza mediante Leaflet Providers y debe conservarse la atribucion exigida por Esri en cualquier deployment.

BACKEND:
- PHP 7.4+ para sincronizacion y construccion del cache.
- cURL o streams HTTP de PHP para comunicacion con servicios externos.

SERVICIOS Y FUENTES DE DATOS:
- Clublog: https://clublog.org/
- LoTW, Logbook of The World: https://lotw.arrl.org/
- HamQTH: https://www.hamqth.com/
- Spothole: https://spothole.app/
- QRZ se utiliza solo como enlace opcional desde los popups; no se usa embedding.

DATOS LOCALES:
- data/dxcc.js contiene el catalogo local de entidades DXCC utilizado para mostrar nombre y codigo.
