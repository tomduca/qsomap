========================================
GUIA DE INSTALACION EN HOSTING
========================================

Esta guia usa File Manager, navegador y Cron de cPanel. No requiere SSH.

1. SUBIR ARCHIVOS

Subi el proyecto a public_html/qsomap/ y verifica que existan:
- config.json
- map-ssb.html, map-digi.html y map-qsl.html
- js/, css/, data/dxcc.js, img/ y fa/
- sync_clublog.php
- sync_lotw.php
- build_cache.php
- sync_daily.sh
- data/
- map-ssb-qrz.php
- make_bg_1x1.php, map600x600.png y background_lu2met_1x1.png

No publiques config.json en un repositorio. Contiene credenciales.

2. CONFIGURAR config.json

Copia config.json.example como config.json y completa las credenciales de las fuentes que uses:
- Clublog: email, password, api_key y callsign.
- LoTW: username, password y days_back.
- HamQTH: username y password, si usaras lookup de grids.
- map: callsign y grid del operador.

3. INICIALIZACION DESDE EL NAVEGADOR

Abre las URLs en este orden y espera a que cada proceso termine:

1. https://tu-dominio.com/qsomap/sync_clublog.php
2. https://tu-dominio.com/qsomap/build_cache.php

Si Clublog no esta configurado o falla, usa este orden alternativo:

1. https://tu-dominio.com/qsomap/sync_lotw.php
2. https://tu-dominio.com/qsomap/build_cache.php

No ejecutes dos PHP al mismo tiempo. El primer PHP genera data/qso_data.json y build_cache.php genera data/qso_cache.json.

4. VERIFICAR EL MAPA

Abre:
- https://tu-dominio.com/qsomap/map-ssb.html
- https://tu-dominio.com/qsomap/map-digi.html
- https://tu-dominio.com/qsomap/map-qsl.html

Si no aparecen datos, verifica en File Manager que data/qso_cache.json exista y tenga contenido.

5. CRON DIARIO

En cPanel, crea un Cron Job permanente a las 02:00 con este comando:

cd /home/TU_USUARIO/public_html/qsomap && /bin/bash sync_daily.sh

Para tu instalación actual:

cd /home/lu2met/public_html/qsomap && /bin/bash sync_daily.sh

sync_daily.sh ejecuta Clublog, usa LoTW como fallback y después reconstruye el cache. El log queda en:

public_html/qsomap/sync_daily.log

El archivo sync_daily.sh debe tener permisos 755 y data/ debe permitir escritura.

6. MAPA ESTATICO PARA QRZ

El mapa estático mide 600 x 600 px. `map-ssb-qrz.php` necesita `data/qso_cache.json` y `background_lu2met_1x1.png`; calcula las posiciones y las rutas al abrirse.

Al instalar o actualizar el generador, y cuando cambie el QTH o el planisferio, configura `map.my_grid` en config.json y ejecuta `make_bg_1x1.php` con PHP GD. El script lee `map600x600.png` y escribe `background_lu2met_1x1.png`. Sin SSH, puedes abrir `https://tu-dominio.com/qsomap/make_bg_1x1.php` en el navegador del hosting. No se ejecuta con el Cron diario. Si lo generas en otra máquina, sube el PNG resultante a `public_html/qsomap/`.

Prueba primero `https://tu-dominio.com/qsomap/map-ssb-qrz.php?v=20261009-1`. En QRZ, usa la URL con un parámetro `v` y cámbialo al publicar una nueva versión:

<iframe src="https://tu-dominio.com/qsomap/map-ssb-qrz.php?v=20261009-1" width="600" height="600" frameborder="0" scrolling="no"></iframe>

Las cabeceras PHP desactivan el caché de la página y el URL del PNG se cambia en cada respuesta. Si QRZ muestra una versión previa, cambia el valor de `v` en el iframe. Un clic en el mapa abre el mapa interactivo SSB en una pestaña nueva.

7. ACTUALIZACION MANUAL

Para una actualización puntual, abre sync_clublog.php y luego build_cache.php. Si usas LoTW como fuente, abre sync_lotw.php y luego build_cache.php.
